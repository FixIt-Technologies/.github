# FixIt Technologies

**Pomoc s domácností v reálném čase.**
Real-time home services for Czechia — from an urgent fix to a scheduled pro.

[fixit.app](https://fixit.app)

---

FixIt is a marketplace that connects households with vetted professionals:

- ⚡ **Realtime** — urgent dispatch; the first available pro accepts and heads out.
- 📅 **Scheduled** — book an appointment that fits your day.
- 🛠️ **Marketplace** — fixed-price small jobs and offers for bigger projects.

## What we build

| Surface | Stack |
|---|---|
| Mobile app (iOS & Android) | React Native · Expo · TypeScript |
| Web | React · TypeScript |
| Platform API | NestJS · PostgreSQL · Redis |

We're a small Czech team that likes to keep complex things simple — TypeScript end-to-end, one monorepo, real E2E tests on real devices.
